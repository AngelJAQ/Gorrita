Acerca de Gorrita

Este es un Proyecto de Investigación y Desarrollo (I+D) que tiene como objetivo desarrollar un modelo que permita predecir el rendimiento del cultivo de cebada y convertirlo en una solución tecnológica funcional. El proyecto busca mejorar la eficiencia y productividad del cultivo de cebada mediante el uso de tecnologías avanzadas y análisis de datos.

Las Tecnologías que se usaron para realizar este proyecto son:
  1. Angular
  2. Angular Material
  3. Node.js
  4. Python
  5. Bootstrap
